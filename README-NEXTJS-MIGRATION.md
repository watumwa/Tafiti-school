# Tafiti School — Next.js Redesign

This working copy contains the first migration foundation for moving the legacy Django-template interface to Next.js without replacing the mature Django business/domain layer.

Start here: [`docs/nextjs-migration-status.md`](docs/nextjs-migration-status.md)

Key principle: Next.js is the presentation layer; the existing Django `app` models and business logic remain the source of truth.
